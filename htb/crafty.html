Initial foothold

Log4j

  1. Install prism launcher (to make minecraft work on kali Linux & arm arch)
  2. Login to the server
  3. Clone the repo, install requirements etc
    1. Start netcat listener → nc -lvnp 9001
    2. Install java 8u20 to the current directory (the exploit needs it in order to work)
    3. Update poc script to make it work on windows
  4. Run POC exploit

    We got a shell as svc_minecraft
