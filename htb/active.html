Decrypt password

This file is usually located in a directory of the SMB shared resources, called SYSVOL, if you find this directory and you have read permissions on it, take advantage of it, and look for the file called groups.xml.
When we have this hash, thanks to the fact that some time ago by mistake Microsoft published the AES key to decrypt this password, here more information, there is a tool called gpp-decrypt, preinstalled in Kali Linux
Interesting msf module to do this automatically: scanner/smb/smb_enum_gpp

Decrypt using gpp-decrypt:

┌──(kali㉿kali)-[~/SIGRed_RCE_PoC]
└─$ gpp-decrypt edBSHOwhZLTjt/QS9FeIcJ83mjWA98gw9guKOhJOdcqh+ZGMeXOsQbCpZ3xUjTLfCuNH8pG5aSVYdYw/NglVmQ
